## Weekly Editing Rules

### 1. Open with synthesis, not inventory
- The TL;DR should summarize the week in 3 bullets.
- Each bullet should describe a trend or direction, not just restate one headline.
- Prefer language like "accelerating", "shifting", "moving toward", "continuing to consolidate".

### 2. `巨头动态 (Tech Giants)` is vendor-first
- Preferred vendor order:
  - `OpenAI`
  - `Gemini`
  - `Anthropic`
- Only include vendors that actually have meaningful items in the weekly window.
- Use the bold vendor subheading with a short theme summary.
- Within a vendor block:
  - strongest official item first
  - supporting items after it
  - use `🔥` only on the most important item in that vendor block

### 3. `智能体与工作流` should synthesize project progress
- Prefer grouping multiple releases from the same project into one bullet.
- OpenClaw and n8n should usually be summarized as project progress, not listed as separate release bullets unless one release is unusually important.
- This section is for:
  - coding agents
  - workflow orchestration
  - agent platforms
  - developer automation

### 4. `开源探索与前沿洞察` is split into two distinct parts
- `基础设施与端侧`
  - practical open source infra, model tooling, diffusion, robotics, on-device AI
- `深度阅读推荐`
  - essays, analysis, reflective blog posts, historical context, strong independent commentary

### 5. Avoid weekly duplication
- If an item appears in `巨头动态`, do not repeat it in another weekly headlines block.
- This weekly template intentionally does not require a separate `全球 AI 行业热点` section if the TL;DR already carries the top-line synthesis.
- Prefer one strong mention plus synthesis over repeating the same story in multiple blocks.

### 6. Tone and writing style
- Write in concise Chinese editorial style.
- Do not mechanically translate headlines.
- Each bullet should explain why the item matters this week.
- Weekly output should feel curated, not like a raw feed dump.

## Why This Weekly Template
- Better suited for forum-style weekly reading.
- Reduces duplication between headline and vendor sections.
- Makes trend synthesis explicit through TL;DR.
- Lets OpenClaw / n8n progress be presented as coherent weekly momentum rather than isolated releases.
