# Workspace Docs

这里放的是补充说明，不是主入口。

阅读顺序建议如下：

1. `CONFIG_NOTES.md`
作用：当前 workspace 的运行约定、默认策略、标准命令。
适合：想知道这份仓库今天应该怎么跑的人。

2. `SCOUT_ATOMIC_TOOLS.md`
作用：原子工具的输入输出契约、每个 tool 的职责边界。
适合：想把这些能力接进 Scout 或别的 runtime 的人。

3. `ANTHROPIC_HTML_SOURCE.md`
作用：Anthropic 为什么按 HTML source 处理，以及提取规则。
适合：想扩展更多 HTML 页面源的人。

4. `SCOUT_REARCHITECTURE.md`
作用：更长期的 Scout 迁移方向和目标分层。
适合：做平台层重构、不是只跑这一个 skill 的人。

如果你只是要运行日报 / 周报，不需要先读完这些文档。
先看仓库根目录：
- `README.md`
- `SKILL.md`
